# Дипломный проект

## Описание

Проект является планировщиком задач, который позволяет для задач задавать правило повторений. В рамках проекта был реализован _backend_ на языке программирования Go.

Из заданий повышенной сложности выполнено создание Docker-образа.

## Файлы для итогового задания

В директории `pkg` находятся файлы backend'а. В `pkg/server` находтся функция запуска сервера. В `pkg/db` находятся функции работы с базой данных. В `pkg/api` файлы с функциями, отвечающие за обработку запросов сервером.

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

## Инструкция по запуску кода

Для запуска сервера локально вне контейнера:

```bash
go run .
```

Для использования Docker контейнеризации нужно сорать образ:

```bash
docker build --tag server:v1 .
```

Затем запустить Docker контейнер:

```bash
docker run -d -p 7540:7540 server:v1
```

После запуска сервер будет доступен по адресу http://localhost:7540.

## Инструкция по запуску тестов

Для запуска всех тестов нужно **запустить сервер** и выполнить:

```bash
go test ./tests
```
